## 👨‍💻 About Me

I'm a **Cybersecurity Professional** based in India, focused on **offensive security, vulnerability assessment, and real-world defensive operations** — helping organizations understand how attackers think and how to stop them.

I'm also a **Real-World Attack Researcher**: I study live attack chains, TTPs, and emerging threats, then **build realistic security labs** used for hands-on teaching and training. Learners get experience with the same threats they'll face in production — not sanitized textbook scenarios.

- 🔭 **Currently Working On:** Real-World Attack Labs · Android Pentesting · IoT Firmware Security
- 🌱 **Currently Learning:** Cloud Security (AWS/Azure) · Advanced Malware Analysis · Exploit Development
- 👯 **Open To:** VAPT Engagements · Red Team Operations · Android/Mobile Pentesting · Malware Analysis · Security Training & Lab Setup
- 💬 **Ask Me About:** VAPT · Android Pentesting · Reverse Engineering · Malware Analysis · CEH/CEI Training · SOC Operations · IoT Hacking · Lab Building · Full Stack Dev
